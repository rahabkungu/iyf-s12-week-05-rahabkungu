## Project Description
This project focuses on learning JavaScript DOM Manipulation and building a To-Do List application.

The DOM lessons help me understand how to select, modify, add, and remove HTML elements using JavaScript.

The To-Do List project allows users to manage their daily tasks, while the daily challenges provide practical exercises to improve my JavaScript and DOM manipulation skills.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Visual Studio Code

- GitHub

## Features
- Add new tasks to the To-Do List.
- Display tasks on the webpage.
- Mark tasks as completed.
- Delete tasks from the list.
- Select HTML elements using JavaScript.
- Modify webpage content dynamically.
- Add and remove HTML elements.
- Change webpage styles using JavaScript.
- Implement a simple dark mode toggle.

## Daily Challenges (Week 5)

### Day 1: Change All Headings to a Random Color
- Select all headings on a webpage.
- Change each heading to a random color using JavaScript.

### Day 2: Create an Element and Add It to the Page
- Create a new HTML element using JavaScript.
- Add the new element to the webpage.

### Day 3: Remove All Images from a Page
- Select all images on the webpage.
- Remove all images using JavaScript.

### Day 4: Copy Content from One Element to Another
- Select two HTML elements.
- Copy content from one element to another using JavaScript.

### Day 5: Build a Simple Dark Mode Toggle
- Create a button for switching between light mode and dark mode.
- Use JavaScript to change the webpage appearance.
